# Бренд «Мосдевелопмент Право» — мини-гайд

## Логотип «Портик»

Золотой фронтон, архитрав и две колонны образуют «П», тонкие диагонали между колоннами — «М». Образ здания суда без клише (без молотков и весов). Словесный знак — «Мосдевелопмент» (Lora) и «ПРАВО» разрядкой (Onest SemiBold), текст переведён в кривые.

Название пишется точно: **Мосдевелопмент Право** (юрлицо — ООО «Мосдевелопмент Право»).

| Файл | Где использовать |
|---|---|
| `public/brand/logo-horizontal.svg` / `.png` | основной, на светлом фоне |
| `logo-horizontal-inverse.svg` / `.png` | на бордовом и тёмном фоне (шапка, подвал сайта) |
| `logo-horizontal-mono-dark.svg` | одноцветная печать, факс, штампы |
| `logo-horizontal-mono-light.svg` | одноцветный на тёмном |
| `mark.svg`, `mark-inverse.svg`, `mark-mono-*.svg` | компактный знак: аватар, соцсети, водяной знак |
| `favicon.svg`, `favicon-16.svg`, `favicon.ico`, `icon-*.png`, `apple-touch-icon.png`, `icon-maskable-512.png` | вкладка браузера, iOS, Android/PWA |
| `social-preview.jpg` | превью ссылок (Open Graph), 1200×630 |

Правила:
- Охранное поле — высота фронтона со всех сторон.
- Минимальный размер: горизонтальный логотип — 120 px по ширине; знак — 16 px (для 16–32 px есть отдельный пиксельный вариант `favicon-16.svg`).
- Нельзя: менять пропорции, перекрашивать в цвета вне палитры, добавлять тени и обводки, ставить на пёстрые фото без подложки.
- Исходники генерируются скриптом `tools/brand/build_kit.py` — правки делать там, а не в SVG вручную.

## Шрифты

- **Unbounded** — заголовки (широкий, молодёжный).
- **Onest** — текст интерфейса (кириллица, хорошо читается мелко).
- **Lora** — только в словесном знаке логотипа.

Все — OFL, раздаются с нашего сервера (`public/fonts`), без запросов к Google с устройств посетителей.

## 3D-иконки

21 иконка (13 направлений, 4 этапа, 4 ценности) отрендерены кодом: `tools/icons3d` (SDF-сцены, WebGL2). Материалы — бордовая эмаль, песочное золото, фарфор. Перерисовать все: `python3 tools/icons3d/render.py --size 512`.

## Движение

Появление блоков при прокрутке, поочерёдный подъём слов в заголовках, 3D-наклон карточек, параллакс сцены в hero, блеск золота, счётчики. Всё отключается системной настройкой «Уменьшить движение» (`prefers-reduced-motion`).
