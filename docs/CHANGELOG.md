# Журнал изменений

## 2.0.0 — 29.10.2026 (готово к приёмке, не опубликовано)

Новая версия сайта, написанная с нуля (доступа к коду старого сайта нет — см. `docs/PROJECT_AUDIT.md`).

### Бренд и дизайн
- Логотип «Портик» (фронтон + колонны = «МП»), полный комплект: горизонтальный, знак, моно, светлый/тёмный, favicon, PWA-иконки, OG-картинка 1200×630, мини-гайд `docs/BRAND.md`.
- Палитра владельца: бордовый `#542531`, вторичный `#762F40`, золото `#C4A477`, фон `#F8F3EE`, текст `#30262A`; 29.10 добавлены тёмные «винные» сцены, винно-красный и светлое золото.
- 21 новая 3D-иконка вместо старых глянцевых (рендер кодом, `tools/icons3d`); вместо стокового рукопожатия — «ручка подписывает документ».
- Шрифты Unbounded + Onest, раздаются со своего сервера.
- Анимации: подъём слов в заголовках, появление при прокрутке, 3D-наклон карточек, параллакс hero, металлический блеск золота, счётчики, бегущая строка. Учитывается «Уменьшить движение».

### Публичная часть
- Все 239 адресов старого sitemap отвечают 200 с теми же title/description; канонический вид — со слешем, без слеша — 301.
- Новые страницы: `/prices/`, `/faq/`, `/contacts/`; `/knowledge/cabinet/` → 301 на `/cabinet/`.
- Умный поиск (SQLite FTS5, учитывает словоформы), калькулятор договорной неустойки.
- Единая форма обращения с согласием на обработку ПД, защитой от ботов и ограничением частоты.
- SEO: sitemap, robots (кабинет закрыт), Open Graph, JSON-LD (Organization/LegalService, FAQPage, BreadcrumbList, Article, Service, Person).

### Личный кабинет
- Вход по паролю и по одноразовому коду на e-mail, регистрация по желанию; обращения привязываются к кабинету по e-mail.
- Главная панель: активные дела, нужные действия, счета к оплате, сроки, последние события.
- Дела с понятными статусами, перепиской, документами и счетами; закладки и заметки; профиль, смена пароля, завершение других сеансов.
- Документы: проверка типа по содержимому, лимит размера, приватное хранилище, выдача только после проверки прав, прогресс загрузки.

### Оплата
- ЮKassa: создание платежа с ключом идемпотентности, подтверждение статуса запросом к API, приём уведомлений с журналом и защитой от повторов, обработка отмены и возврата, чеки 54-ФЗ (опционально).
- Тестовый провайдер для разработки; в production запрещён на уровне конфигурации.

### Панель юриста
- Обращения → дело в один клик, смена статуса с комментарием, назначение ответственного, срок и следующий шаг, внутренние заметки, загрузка документов клиенту, выставление счетов.

### Безопасность
- CSP без inline-скриптов, HSTS, X-Frame-Options, nosniff; CSRF (Origin + токен); сессии в БД по хешу; scrypt для паролей; лимиты попыток входа, кодов, форм и загрузок; защита от фиксации сессии и открытых редиректов; журнал без персональных данных.
