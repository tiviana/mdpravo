## 2. Адаптивность `tests/e2e/responsive.py` — 189 проверок, 0 проблем

Ширины из ТЗ: 320, 360, 390, 430, 768, 1024, 1280, 1440, 1920 px. Страниц: 17 публичных (анонимно; 29.10 добавлены срочный алгоритм, шаблон с заполнением, тема, два каталога сервисов, политика, профиль руководителя) и 4 кабинета (после входа; проверяется, что открылась именно эта страница, а не вход). Критерии: нет горизонтальной прокрутки, есть `h1`, интерактивные элементы не ниже 36 px, нет ошибок JS и консоли.

По ходу найдено и исправлено: 29.10 — переполнение формы заполнения шаблона на 320–360 px и профиля руководителя на 768 px; ранее — переполнение шапки на 320–430 px, переполнение плашки «Сотрудничество» на 320 px, блокировка inline-стилей политикой CSP (ломала задержки анимаций).

## 3. Ручной сквозной сценарий в браузере

Вход клиента → дело → сообщение специалисту → загрузка PDF → отказ поддельному «PDF» с понятной ошибкой → счёт → переход к оплате (тестовая страница) → «Оплатить успешно» → возврат, статус «Оплачен»; чужое дело → 404. Ошибок JS нет. Найдено и исправлено: номера дел с заглавными буквами не проходили роутер, огромная иконка «Выйти», сжатый счёт в боковой колонке, размер мелких файлов «0.0 МБ».
