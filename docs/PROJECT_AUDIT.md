# Аудит проекта mdpravo.ru

Дата аудита: 27.10.2026. Источник фактов: публичный сайт https://mdpravo.ru, проверенный во встроенном браузере (sitemap, разметка страниц, сетевые запросы кабинета). Исходного кода и доступа к серверу текущего сайта у команды **нет**. Владелец решил делать новый проект с нуля в репозитории `tiviana/mdpravo`.

Обозначения: **[факт]** — проверено на живом сайте; **[вывод]** — следует из фактов; **[не установлено]** — проверить невозможно без кода, БД или доступа к серверу.

## 6. Блокеры

1. **Нет исходного кода и БД старого сайта.** Без дампа нельзя перенести аккаунты, обращения, счета и историю платежей. Нужен экспорт таблиц пользователей, заявок, счетов и платежей и описание алгоритма хеширования паролей.
2. **Платёжный провайдер не известен.** Реализована интеграция с ЮKassa и тестовый провайдер для разработки. Нужны: подтверждение выбора провайдера, `shopId` и секретный ключ (только через переменные окружения).
3. **Почта для кодов входа.** Нужен SMTP-ящик (логин/пароль приложения) для отправки одноразовых кодов.
4. **SMS-коды и Яндекс ID** не реализованы: нужен договор с SMS-провайдером и OAuth-приложение Яндекса.
5. **Полные тексты статей и файлы шаблонов** не скопированы в репозиторий: их нужно импортировать скриптом на стороне владельца (это контент компании, перенос — её решение).
6. **Фотографии специалистов** не перенесены: нужны исходные файлы от компании. До этого показываются инициалы.
7. **Правовые требования (152-ФЗ, локализация, хранение документов)** — нужен список, подтверждённый ответственными специалистами компании (см. `docs/DEPLOYMENT.md`, раздел «Персональные данные»).

## 7. Ограничения среды разработки

- Реестры npm и PyPI недоступны, поэтому проект написан **без внешних зависимостей** на Node.js ≥ 22.13 (`node:http`, `node:sqlite`, `node:crypto`, `node:test`).
- `node:sqlite` в Node 22 помечен как экспериментальный. Слой хранения изолирован в `src/db`, чтобы позже перейти на PostgreSQL без переписывания бизнес-логики.
- Шрифты взяты из репозитория Google Fonts на GitHub (лицензия OFL) и раздаются со своего сервера — без запросов к Google с устройств посетителей.
